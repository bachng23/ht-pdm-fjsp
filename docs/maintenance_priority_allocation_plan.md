Small exact mechanism metric: under each deployed policy's state occupancy, selection regret = best optimal cost-to-go among matchings of its selected machine set minus unrestricted optimal value; allocation regret = its matching cost-to-go minus that conditional best. The two cumulative expected regrets must sum to the exact policy gap. This is a decomposition relative to optimal future continuation, not an independent causal attribution or oracle supervision. Record per-machine starts by technician and per-technician busy ticks. Separate failed deferral with more than the maximum service duration left from late-horizon deferral; this is a conservative timing diagnostic, not proof of irrationality.

## Environment, clock and costs
Machines are operating, failed waiting, or under maintenance; technicians are idle or service-occupied. No per-technician queue/reservation. At physical time t choose a feasible partial matching of unassigned machines to compatible idle technicians. All selected services start simultaneously; decoder order has no physical meaning. PM cost=1, CM=2, unavailable machine cost=6 per interval, new failure cost=15. One unavailability charge per machine even if failed+servicing. Pending corrective wait is a diagnostic, not another duplicate queue penalty.
For [t,t+1): commit new services/pay start cost; charge occupied/failed machines' unavailability; only operating machines age and undergo sampled age-threshold hazard; decrement service remaining; at t+1 complete/release and restore age=floor(old_age*(1-effectiveness)), clear failed. Operating age is frozen during failed waiting/service. Failed wait increments only while unassigned; pending time resets at completion. Terminal t=H stops accrual, unfinished jobs get no completion credit beyond H, start cost remains charged; report unfinished jobs and failed demands at terminal. No hidden terminal bonus or repair-forcing mask. Durations integer >=1, zero means incompatible; every machine and technician has a compatible edge. No technician learning.
Initial healthy ages are independently uniform [0,failure_age-1], resources idle, no initial failures. Train and evaluation use same reset distribution; timeline unit tests also cover initial failed states. Random streams for initial state and full time×machine failure grid are separately derived from episode seed using SHA256 role tags. Grid draws do not depend on policy eligibility. Test config generation has its own tagged stream.
Observation: machine [scaled age, failed, scaled pending wait, in service, scaled remaining service, current operating hazard]; technician [idle, scaled remaining, assigned-machine failed]; edges [compatibility, scaled duration, restoration, active-link]; global [remaining horizon, failure threshold, probability, PM/CM/unavailability/failure costs]. The encoder also derives public entity counts N/4,K/2 from existence masks. Fixed scales age8,time12,cost20, no fitted normalization or fixed ID embeddings. Padded training batch entities carry explicit existence masks; inference supports variable N/K. All compared policies see the same public static parameters. No future shocks or oracle labels.

## Limits and interpretation
Controlled contrasts diagnose value of learned priority/allocation within this new coordinated policy contract. They do not isolate all architectural changes vs old QMIX. PPO does not guarantee avoidance of STOP collapse or starvation; report these rather than forcing repairs. Entity encoders permit variable shapes, but unknown-size transfer remains empirical. Finite horizon rewards may rationally leave late failures unserved; distinguish late terminal effects from earlier abandonment. Maintenance-only unavailability cost is a production-loss proxy, not measured FJSP makespan. Small DP shares source dynamics, not independent proof of real-world validity. Keep every failed scientific gate, no thresholds relaxed after outcomes.
